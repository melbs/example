the [University of Minnesota GitHub](https://githib.umn.edu/).

## Images

Images are similar to links. Once you learn how to do links, images ae
just a small step.
To add an image, *it's basically a link* to an image that ges displayed
in the Markdown document.
Technically, *all images are inline*. 

Inline images are helpful when you need to write about something like
an icon. Such as
"Press the ![a circle with a vertical line passing through it](power.png) Power button to turn on the device."

If you need to display an image
as a block element (like large graphic, such as a chart or large photo)
then put it on its own paragraph.

## Tables

Sometimes, it's helpful to include a table. A table can be a reference for
a list of things that wouldn't otherwise fit into a list.
Here's an example of a list: Let's say I wanted to show some of the most useful
formatting commands from an old markup system called nroff (also troff).

* `.sp` adds blank lines of space
* `.br` breaks a line
* `.ti` adds temporary indent

A few items might be better as a list, but longer than that might be better
as a table.
To make a table in Markdown, you basically "draw" the table using characters
from your keyboard.

| command | what it means |
| ------- | ------------- |
| `.sp`   | adds blank lines of space |
| `.br`   | breaks a line             |
| `.ti`   | adds temporary indent     |
